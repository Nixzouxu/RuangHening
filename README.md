# Innerly
Innerly ("The Quiet Space") is a privacy-first mental wellness platform designed for Indonesian students and young adults navigating the everyday pressures of academic life, social expectations, and emotional wellbeing. At its core, Innerly gives users a quiet, judgment-free space to write daily journal entries, understand their emotional patterns through AI-powered sentiment analysis, talk through difficult moments with an empathetic AI chatbot, visualize their mood trends over time through an intuitive dashboard, and ground themselves with guided mindfulness and breathing exercises.

The frontend is a bilingual (Indonesian/English), installable Progressive Web App built with React, TypeScript, and Tailwind CSS designed with an offline-first experience so users can keep journaling even without a stable connection, with a calm, accessible interface that avoids clinical or intimidating design patterns common in mental health apps.

Behind the scenes, Innerly runs on an Express.js/TypeScript API backed by PostgreSQL, built with the understanding that mental health data deserves the same rigor as any sensitive personal information: journal and chat content is encrypted field-level with AES-256-GCM before it ever reaches the database, passwords are hashed with Argon2id, sessions are secured with rotating JWT access/refresh tokens, PostgreSQL Row-Level Security enforces data isolation as a second line of defense, and Redis-backed rate limiting protects both the system and shared third-party AI quotas from abuse. Sensitive text is anonymized server-side before any AI processing, with data handling designed around UU PDP (Indonesia's Personal Data Protection Law).

Innerly was built as a full end-to-end product from user research and UI/UX flow design, through frontend implementation, to a production-grade backend architecture spanning authentication, database design, deployment, and observability.
